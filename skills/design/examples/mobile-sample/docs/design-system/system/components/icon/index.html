Design system / Components / Icon

Icon

In review updated 2026-11-01 · Design, not a working product

Icons are drawn with a 2 px stroke in the colour of the text beside them, in two sizes. An icon repeats a word and never replaces one.

Every state

Keyboard and screen reader

None. An icon is not a control. The word beside it is what a screen reader reads, and a back button carries its own label.
