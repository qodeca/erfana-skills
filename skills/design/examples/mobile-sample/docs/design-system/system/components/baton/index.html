Baton

In review updated 2026-11-01 · Design, not a working product

Three steps in one fixed place: who holds the shift now. A check, a ringed clock, a cross, or an empty ring says the state with the words, and colour only repeats it. The current step is never filled marigold, because the baton cannot be tapped.

Every state

Keyboard and screen reader

A phone has no keyboard of its own, so this covers a paired keyboard and the double-tap of VoiceOver and TalkBack.
