Shift ticket

In review updated 2026-11-01 · Design, not a working product

The system’s signature: the shift time set as large as the screen allows, with a colour band, a word, and an icon for day or night. A nurse should know which shift this is from arm’s length.

Every state

Keyboard and screen reader

A phone has no keyboard of its own, so this covers a paired keyboard and the double-tap of VoiceOver and TalkBack.
