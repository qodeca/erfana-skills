Panes

In review updated 2026-11-01 · Design, not a working product

One grid places the same parts for every size, so a bigger screen earns more panes, never bigger phone parts. A phone shows one pane. From 600 the list sits beside the main pane, and from 960 the status gets its own column. The markup of the two tablet frames below is identical: only the width differs.

Every state

Keyboard and screen reader

Panes read in markup order: list, main, status, then the action bar. Opening a list item moves focus to the main pane, and on a phone the back action returns focus to that item.

KeyResultFocus ends on
TabMoves through each pane in reading orderThe next control
EnterOpens the list item in the main paneThe start of the main pane
