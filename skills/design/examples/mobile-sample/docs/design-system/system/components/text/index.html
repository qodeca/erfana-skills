Design system / Components / Text

Text

In review updated 2026-11-01 · Design, not a working product

Four text classes, each resetting its own box, so they work on any element. No title goes above 22, so the shift time stays the largest thing on a screen.

Every state

Keyboard and screen reader

None. Text has no behaviour of its own. .title and .heading sit on real heading elements, so a screen reader can move between them.
