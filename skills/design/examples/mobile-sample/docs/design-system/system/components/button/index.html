Design system / Components / Button

Button

In review updated 2026-11-01 · Design, not a working product

One filled marigold button per screen, always at the bottom. Its dark edge keeps it clear of the light surface, because marigold alone reaches only 1.7:1 against sand.

Every state

Keyboard and screen reader

A phone has no keyboard of its own, so this covers a paired keyboard and the double-tap of VoiceOver and TalkBack.

KeyResultFocus ends on
Enter or SpaceRuns the actionThe button, or the next screen’s title
