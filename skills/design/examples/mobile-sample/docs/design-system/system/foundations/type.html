Type

In review updated 2026-11-01 · Design, not a working product

System fonts, so text follows the phone’s size setting, with no download: SF Pro on iOS and Roboto on Android, each named in tokens.json. No font ships with the review pages, so without Roboto installed a Mac draws Android frames in a fallback. Sizes are numbers read as pt on iOS and sp on Android. The large-text mode multiplies them, so review pages can draw 200% text. Size jumps hard from the body text to the time, because time is what a nurse looks for. Times use equal-width numerals, so they line up down a list.
