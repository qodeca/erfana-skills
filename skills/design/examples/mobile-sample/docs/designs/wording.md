# Wording

Shared terms. All are unconfirmed guesses until a nurse and a manager have read them.

| Use | Avoid | Why |
|---|---|---|
| Offer a shift | Drop, post, trade | Says what the nurse does. "Drop" sounds like abandoning patients |
| Take it, accept | Claim, pick up | Plain words, and they translate well |
| Colleague | Coworker, staff member | From the brief |
| Manager, ward manager | Approver, admin | A person, not a role in software |
| Approve, decline | Reject, deny | "Decline" is gentler, and a nurse reads this tired |
| You are still on this shift | Request unsuccessful | States the fact that matters most |
| Can't take it | Ineligible | Plain words |
| Needs more rest | Rest violation | Says nothing personal, and does not accuse |
| Over weekly hours | Overtime breach | Same |
| Missing a required skill | Not qualified | Same |
| Goes to your manager | Pending approval, submitted | Says what happens next, in plain words |
| Go back | Back, Return | A verb, like every other button, and easy to translate |
| Say no | Decline, reject | "Decline" belongs to the manager. A colleague only answers a request |
| Keep offer, Keep request | Cancel, Dismiss | "Cancel" next to "Cancel offer" would be ambiguous |
| Shift | Duty, rota slot | From the brief. Check against local use: "rota" in the UK |
