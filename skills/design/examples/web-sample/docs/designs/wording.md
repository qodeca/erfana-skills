# Wording

The shared terms on the booking pages. All are drafts until the clinic confirms them.

| Term | Means | Do not say |
|---|---|---|
| Session | One appointment: "First visit" at 60 minutes, or "Follow-up session" at 45 | Appointment, on screen |
| Booking | A session a patient has saved | Reservation |
| Booked | Saved; a text follows | Confirmed |
| Move booking | Change the time of a booking | Reschedule |
| Cancel booking | End a booking. The safer choice beside it is "Keep booking" | Delete |
| Taken | A time someone else holds | Unavailable |
| Selected | The time a patient has picked, always with a tick | Chosen, as a label |
| Free | A staff-list time with no patient. On the week: how many times a day has left, as "6 free" or "None free" | Open, Available |
| Closed | A day the clinic does not open | Shut |
| New time | The time a booking is moving to, before it is saved. "Moving to" while it saves | Target |
| Your booking | The patient's own time on the move screen | Yours |
| Not open | A day past the booking window | Unavailable |
| Next | The first booked session after the current time | Up next |
| Try again | Repeat the step that failed | Retry |
