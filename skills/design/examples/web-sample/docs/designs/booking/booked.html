Booked

Moving, cancelling, and changing the number all start here. Judge whether the patient can see at once that the booking stands, in the failed states above all.

Open questions
  • Assumed: a tablet is touch only. A tablet with a keyboard or mouse would need the desktop hover and focus states.
  • Assumed: the two tablet sizes are one 768 by 1024 screen, upright and on its side. Widths between the drawn sizes take the layout below them, and a phone on its side, which is short rather than narrow, is not drawn.
  • Assumed: clinic name, phone number, and address are placeholders. Real ones change line lengths on the card.
Sizes

How this adapts: Each state is drawn desktop, tablet, tablet landscape, then phone. From an upright tablet up, the main pane and the action pane stand side by side. On a phone they stack, with the actions at the bottom.

  • A tablet held upright is drawn as touch only, so it has no hover or keyboard focus state. Its layout is in the state booked.
  • A tablet on its side is drawn as touch only, so it has no hover or keyboard focus state. Its layout is in the state booked.
  • A phone is drawn as touch only, so it has no hover or keyboard focus state. Its layout is in the state booked.
