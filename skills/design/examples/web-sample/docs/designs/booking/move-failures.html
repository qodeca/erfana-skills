Move a booking: failures

Every failure here keeps the old booking. Judge whether the patient reads that first.

Open questions
  • Assumed: a tablet is touch only. A tablet with a keyboard or mouse would need the desktop hover and focus states.
  • Assumed: the two tablet sizes are one 768 by 1024 screen, upright and on its side. Widths between the drawn sizes take the layout below them, and a phone on its side, which is short rather than narrow, is not drawn.
Sizes

How this adapts: Each state is drawn desktop, tablet, tablet landscape, then phone. From an upright tablet up, the main pane and the action pane stand side by side. On a phone they stack, with the actions at the bottom. A failed load and a failed save keep the picker, so its button does not move.

Every state on this page is drawn at every size, so no exception is recorded.
