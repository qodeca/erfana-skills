Choose a time: failures

When no time can be picked, the way out sits where the main action sat. Judge whether each state says what happened.

Open questions
  • Assumed: a tablet is touch only. A tablet with a keyboard or mouse would need the desktop hover and focus states.
  • Assumed: the two tablet sizes are one 768 by 1024 screen, upright and on its side. Widths between the drawn sizes take the layout below them, and a phone on its side, which is short rather than narrow, is not drawn.
  • Assumed: online booking opens 6 weeks ahead. The number is a guess. The clinic decides.
  • Assumed: clinic phone number is a placeholder.
Sizes

How this adapts: Each state is drawn desktop, tablet, tablet landscape, then phone. By width, the picker has four columns on a desktop, three panes on a landscape tablet, two on an upright tablet, and one on a phone, where the week becomes seven cells and the actions move to the bottom.

  • A tablet held upright is drawn as touch only, so it has no hover or keyboard focus state. Its layout is in the state choose-error.
  • A tablet on its side is drawn as touch only, so it has no hover or keyboard focus state. Its layout is in the state choose-error.
  • A phone is drawn as touch only, so it has no hover or keyboard focus state. Its layout is in the state choose-error.
