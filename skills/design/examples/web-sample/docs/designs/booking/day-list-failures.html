Staff day list: failures

A list at reception must never mislead. Judge whether staff can tell a stale list from a current one, and whether a failed day change can ever show the wrong day's patients.

Open questions
  • Assumed: a tablet is touch only. A tablet with a keyboard or mouse would need the desktop hover and focus states.
  • Assumed: staff sign in with a work email and a password, and a signed-out person sees the refused state.
  • Assumed: the list refreshes on its own while open. How often is open.
Sizes

How this adapts: Each state is drawn desktop, tablet, tablet landscape, then phone. The list reads the width of its own pane: six columns on a desktop, five on a landscape tablet, and stacked rows on an upright tablet and a phone. The next session keeps its own pane, and on a phone it comes first and the day buttons drop to the bottom.

  • A tablet held upright is drawn as touch only, so it has no hover or keyboard focus state. Its layout is in the state error.
  • A tablet on its side is drawn as touch only, so it has no hover or keyboard focus state. Its layout is in the state error.
  • A phone is drawn as touch only, so it has no hover or keyboard focus state. Its layout is in the state error.
