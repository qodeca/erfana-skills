Cancel a booking: results

Judge whether a patient can ever misread the result, above all when cancelling fails.

Open questions
  • Assumed: a tablet is touch only. A tablet with a keyboard or mouse would need the desktop hover and focus states.
  • Assumed: the two tablet sizes are one 768 by 1024 screen, upright and on its side. Widths between the drawn sizes take the layout below them, and a phone on its side, which is short rather than narrow, is not drawn.
  • Assumed: a cancelled session costs nothing. If a late fee exists, the cancel state must say so.
  • Assumed: online changes close 24 hours before a session. The number is a guess. The clinic decides.
Sizes

How this adapts: Each state is drawn desktop, tablet, tablet landscape, then phone. From an upright tablet up, the main pane and the action pane stand side by side. On a phone they stack, with the actions at the bottom.

Every state on this page is drawn at every size, so no exception is recorded.
