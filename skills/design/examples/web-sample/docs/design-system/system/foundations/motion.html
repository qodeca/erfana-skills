Motion

Draft updated 2026-11-01 · Design, not a working product

Motion stays quick, and only one thing moves with intent: the strip presses on from the left, from 98% width, so choosing feels like smoothing tape down. With reduced motion it appears at once, and the colour change is still the feedback.
