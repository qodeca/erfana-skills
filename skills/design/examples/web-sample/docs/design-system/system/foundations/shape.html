Shape

Draft updated 2026-11-01 · Design, not a working product

Everything is flat: plaster and tape have edges, not glows, so there are no shadows. Physiotherapists round the corners of tape so it stays on, so strips and buttons carry a soft corner, and cards stay nearly square.
