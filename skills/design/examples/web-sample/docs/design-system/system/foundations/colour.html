Design system / Foundations / Colour

Colour

Draft updated 2026-11-01 · Design, not a working product

Surfaces are warm and flat, edges are ink, and each screen carries one coral strip. Coral marks what is picked, next, or confirmed, and actions are ink, so the two never compete.
