Design system / Components / Time slot

Time slot

A free time is one row on the rail, read time first. Only the chosen slot wears the coral strip, and the strip always comes with the word "Selected" and a tick. The strip crosses the rail but the time stays in line with the times around it. Physiotherapists round the corners of tape so it stays on; the strip's corners do the same.

Every state, light theme

Each row names its state. A slot has no loading or error state of its own: the list around it carries those.

Smallest size, 320 wide

The time column stays fixed, so times still align. The longest name wraps inside its column, and the row grows taller instead of clipping.

Default, selected, and taken, dark theme

The strip softens, and its ink edge goes, because the fill alone clears 3:1 on the dark surface.

Motion

The strip presses on from the left over 240 ms, from 98% width, so choosing feels like smoothing tape down. With reduced motion it appears at once, and the colour change is still the feedback.
